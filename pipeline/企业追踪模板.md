# 企业追踪模板

> 用表格管理你的投递、信号和下一步。不追踪 = 混乱；只记状态、不记行动 = 停滞。

> **隐私提示：** 先复制到你的私有工作区再填写。公开分享时只用公司别名或行业描述，不记录真实联系人、邮箱、聊天记录或截图。详见 [PRIVACY.md](../PRIVACY.md)。

---

## 使用说明

1. 每个准备投递或正在跟进的机会占一行。
2. 每行必须有「简历版本、下一步行动、到期日」；它们让记录变成可执行任务。
3. 每周用 [求职闭环看板](求职闭环看板.md) 回顾一次：哪些信号值得放大、哪些策略该停止。
4. 只记录你愿意在自己的私有副本里长期维护的信息；公开贡献必须脱敏。

### 状态说明

| 状态 | 含义 | 下一步行动 |
|------|------|-----------|
| 📝 已投递 | 简历已发送 | 设定 3–5 个工作日后的检查日 |
| 📞 沟通中 | 已收到有效沟通 | 明确对方问题、准备材料或确认时间 |
| 📋 面试中 | 已安排或正在进行面试 | 面试前准备，结束后 24 小时内复盘 |
| ⏳ 等待中 | 对方承诺后续联系 | 设提醒，在约定时间后礼貌跟进 |
| ✅ 已 offer | 收到正式 offer | 记录评估标准与决定截止日 |
| ❌ 已结束 | 被拒、主动放弃或机会关闭 | 记录原因、保留可复用的市场信号 |
| ⏸️ 无回复 | 超过预定检查期仍无回应 | 标记并停止持续占用注意力 |

## 跟进节奏

- 投递后 **3–5 个工作日** 未回复 → 根据渠道规则决定是否发一次简洁跟进；
- 面试后 **24 小时内** → 完成复盘，必要时发送感谢或补充材料；
- 对方说「稍后联系」→ 记录约定日期，过期后礼貌跟进一次；
- 收到 offer 后 → 记录决定截止日、关键条件与待确认问题，再作决定；
- 连续两周无有效推进 → 在闭环看板中检查目标、证据或渠道，只测试一个改动。
