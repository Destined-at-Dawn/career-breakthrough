# Privacy & Public-Contribution Boundaries

Career Breakthrough is a public repository. Treat every committed file, Issue, pull request, Discussion, screenshot, and external link as public by default.

## Keep these private

Do **not** publish any of the following here:

- real name, phone number, email, address, student ID, government ID, or account credentials;
- school or employer names when they can identify you or another person;
- recruiter, interviewer, teacher, mentor, classmate, or colleague names;
- unredacted resumes, offer letters, interview recordings, chat screenshots, calendars, job-platform exports, or private feedback;
- local absolute paths, internal links, private repositories, or files containing secrets.

## Use safe replacements

| Sensitive detail | Public replacement |
|---|---|
| Employer | `A 公司` / `某半导体团队` / `某消费互联网公司` |
| School | `某双非院校` / `某 211` / `某海外院校` |
| Person | `面试官` / `技术负责人` / `指导老师` |
| Date | Month or quarter when day-level precision is unnecessary |
| Resume contact block | `[姓名]` / `[邮箱]` / `[电话]` |

## Before opening a public contribution

1. Work from a private copy of your resume and tracking board.
2. Replace identifying names and links with aliases or categories.
3. Remove metadata from screenshots, and prefer text summaries over screenshots.
4. Include only facts you are comfortable making public permanently.
5. Re-check every URL and attachment, not only the Markdown text.

## How templates are intended to be used

Templates in this repository are starting points. Copy them locally, add your own details privately, and only contribute a separately anonymized version when it has broad value for others.

For success stories and pull requests, also follow [CONTRIBUTING.md](CONTRIBUTING.md).
