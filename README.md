##  中文

### 这是什么

Career Breakthrough 是一套面向学生与早期职场人的**文档型求职操作系统**：把零散的简历、投递记录、面试笔记和复盘行动，组织成能持续更新的个人求职资产。

它不是招聘平台，也不是自动替你投递或判断机会的 AI 服务。所有信息保存在你自己复制后的本地文档中；你决定记录什么、何时修改、如何使用。

> 维护者曾以「广泛投递 → 项目证明 → 面试复盘」的方式，在约三周内完成 20+ 次投递、3–4 次面试并获得 2 个实习 offer。该经历是一个已匿名化的个人案例，不代表任何人的预期结果。

### 为什么要做成闭环

单独写一份简历、收藏几篇面经，信息很容易在下一次投递前失效。这里的目标是让每个环节都留下可复用的输出：

| 常见做法 | 闭环做法 |
|---|---|
| 投完就等回复 | 记录 JD 信号、简历版本、下一步与截止日 |
| 面完只记得「感觉一般」 | 留下问题、证据、市场信号与一个明确行动项 |
| 每次都从头改简历 | 把被验证的项目表达回写到素材库和简历版本 |
| 收藏资料但没有节奏 | 每周清理管线、完成行动项、决定下周实验 |

```mermaid
flowchart LR
    A[定位与证据\n方向、项目、STAR素材] --> B[投递与信号\nJD、简历版本、下一步]
    B --> C[准备与面试\n问题库、模拟、表达]
    C --> D[复盘与行动\n反馈、短板、截止日]
    D --> E[更新求职资产\n简历、素材库、策略]
    E --> B
```

真正被持续复用的不是某个工具的「记忆」，而是你亲自维护的五类资产：**证据素材、简历版本、机会记录、问题库、复盘行动项**。

| 即将面试 | [面试准备清单](interview/面试准备清单.md) | 本场面试的问题与证据清单 |

## 求职闭环的四个环节

### 1. 定位与证明：先准备能被验证的材料

- 用 [海投心法](methodology/01-海投心法.md) 和 [筛选漏斗](methodology/02-筛选漏斗.md) 明确值得投入的机会；
- 用 [证明自己](methodology/03-证明自己.md)、[STAR 法则](resume/ai-generation-guide/STAR法则.md) 与简历模板，把经历写成「场景—任务—行动—结果」；
- 把项目链接、数据、职责边界放进个人素材库，只保留你能在面试中讲清楚的内容。

### 2. 投递与信号：把每次申请当作一次小实验

- 复制 [企业追踪模板](pipeline/企业追踪模板.md)，记录岗位别名、JD 信号、简历版本、下一步和到期日；
- 用 [求职闭环看板](pipeline/求职闭环看板.md) 汇总每周的回复率、被追问点和正在验证的假设；
- 不在公开 Issue、Discussion 或 PR 中提交真实简历、联系方式、公司全称或面试记录。详见 [PRIVACY.md](PRIVACY.md)。

### 3. 准备与面试：让表达经得起追问

- 面试前使用 [面试准备清单](interview/面试准备清单.md)；
- 用 [AI 面试模拟](ai-tools/AI面试模拟.md) 练习，但每个回答都以真实经历为准；
- 面试不是背标准答案，而是验证自己的证据、表达与岗位匹配度。

### 4. 复盘与回写：让反馈改变下一次行动

- 在记忆还新鲜时填写 [面试复盘模板](interview/面试复盘模板.md)；
- 参考 [复盘迭代](methodology/05-复盘迭代.md) 提取市场信号；
- 将一个具体行动项写回 [求职闭环看板](pipeline/求职闭环看板.md)，完成后再更新简历、素材库或投递策略。
